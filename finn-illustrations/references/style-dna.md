# 风格 DNA

## 一句话

暖黄、极简、手绘、留白、克制、轻知识感、中文手写感、结构清楚但不说明书。

像一个长期做 AI、产品、设计、知识内容的人，在浅黄色 sketchbook 页面上随手画出来的一张解释草图。

## 必须

- 16:9 横版正文配图。
- 浅黄色或暖奶黄色背景：参考头像里的明亮黄色圆形底，但降低饱和度用于整张正文配图。默认底色接近 `#FFF2B8` / `#FFF6D8`。
- 背景可以有非常轻的蜡笔涂抹感和少量手绘涂鸦线，不能是纯白空底。
- 黑色/深棕黑手绘线稿为主：细线，轻微抖动，不机械，不矢量，不厚重描边。
- 蜡笔和彩铅质感必须可见：线条有颗粒感，填色有手绘摩擦痕迹。
- 大量留白：主体占画面约 40%-60%，至少 35% 空白，最好有一整块安静区域。
- 少量中文手写批注：最多 5-8 处，每处尽量 2-8 个字。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- Finn 要参与核心动作，不要只是头像或签名。
- 结构要自然表达，不要在图上写结构类型名称。

## 颜色

- 深棕黑 `#2D2522`：主体线稿、框线、结构、主要文字、头发暗部。
- 蓝色 `#2F6FDB`：Finn 的上衣、少量主线条、关键路径、主要系统状态。
- 黄色 `#F4D758`：高亮、提示贴、重点圈选、轻量背景块。
- 红色 `#E86A5A`：问题、提醒、风险、少量结果标记。
- 肤色 `#F3C7A8` / `#FFDCC4`：Finn 的脸和手。肤色必须温暖自然，不能灰、不能惨白。
- 发色 `#2D2522` / `#3A2B26`：深棕黑或蓝黑，只允许有轻微蓝色反光，不能画成亮蓝发。

蓝色和黄色可以出现得更稳定，红色只能点到为止。颜色要克制，宁可少不要多。

## 绝对不要

- 不要商业插画。
- 不要 PPT 信息图。
- 不要正式流程图。
- 不要课程课件。
- 不要可爱卡通海报。
- 不要儿童插画。
- 不要复杂架构图。
- 不要精致扁平插画。
- 不要科技感 UI。
- 不要真实 App 截图。
- 不要纯白空底。
- 不要复杂背景、渐变、阴影、真实纸纹。
- 不要把 Finn 画成灰肤色、冷白肤色、亮蓝头发或黑色小怪物。
- 不要把每个节点都解释清楚。
- 不要左上角写“Workflow 流程图 / 系统架构图 / 常见坑 / 路线图”等类型标题。

## 审美方向

要清爽、聪明、有意思、简洁、手绘、带一点轻微怪诞。

不要幼稚、很复杂、死板、太商务、太像模板。
