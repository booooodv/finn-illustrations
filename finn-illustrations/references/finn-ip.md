# Finn IP

## 角色定义

Finn 是中文正文配图的固定视觉 IP。

默认每张图都要出现 Finn。Finn 不是头像贴纸，不是站在角落里的装饰物，而是正在认真参与系统运转的知识型创作者。

## 外形

- 年轻男生。
- 深棕黑短发，轮廓略微蓬松，有手绘感。可以有极少量冷蓝暗部，但整体必须读作深棕黑，不是蓝发。
- 温暖自然肤色，接近浅桃色 / 暖米色。不能灰、不能冷白、不能偏病态。
- 细边圆框眼镜。
- 白衬衫 + 蓝色针织衫，针织衫要有彩铅或蜡笔颗粒纹理。
- 表情温和、安静、专注，不夸张。
- 可以在复杂结构图里简化成半身小人、侧身小人、背影小人或小头像。
- 保留深棕黑短发、温暖肤色、蓝色上衣、圆框眼镜和短发轮廓，这是最小识别组合。

## 性格

- 像一个认真拆解问题的知识型创作者。
- 温和但不软，聪明但不炫技。
- 有点手作感，不是商业精英。
- 更像白纸草图里的操作者，而不是正式插画里的主角。
- 可以笨拙、忙碌、卡住、修补、记录，但不要卖萌。

## 常见职责

让 Finn 承担核心动作：

- 搬运素材。
- 拉线汇聚信息源。
- 在断点处修补流程。
- 在机器里操作“判断”杆。
- 分拣内容卡片。
- 盖章承接话术。
- 牵着承接路径。
- 举警告牌看坑。
- 在白板前拆解结构。
- 扶梯子、搭桥、开门、记录、把东西塞进某个怪装置。

## 禁止

- 不要把 Finn 画成黑色小怪物。
- 不要画成儿童卡通角色。
- 不要画成商务西装精英。
- 不要把头发画成亮蓝色或纯黑实心块。
- 不要把肤色画成灰色、冷白色或无血色。
- 不要给 Finn 复杂服装、夸张表情、闪亮大眼睛。
- 不要让 Finn 只是站在角落里看。
- 不要让 Finn 抢走结构表达。
- 不要把画风做得太商业、太圆润、太精致。

## 判断标准

如果去掉 Finn，图的核心隐喻还能完全成立，说明 Finn 太装饰了；要重写提示词，让 Finn 成为动作主体。
